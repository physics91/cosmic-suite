# Digital Cosmos

**A complete universe simulator in a single HTML file.**

No frameworks. No build tools. No dependencies. Just open `index.html` in a browser.

---

## What is this?

An interactive universe simulator that evolved through 61 iterations from a simple particle system into a complete cosmos — with physics, astronomy, biology, civilization, philosophy, music, poetry, and self-awareness.

**4300+ lines | 237 functions | 288KB | 78 achievements | 60 FPS**

## Quick Start

```
open index.html
```

Or serve it:
```
python3 -m http.server 8765
# visit http://localhost:8765/index.html
```

## Systems

- **Physics** — N-body gravity, spacetime fabric, quantum entanglement, gravity brush
- **Astronomy** — 6 star classes, blackbody colors, planets, nebulae, black holes, pulsars, comets, asteroid belts, binary stars, constellations
- **Biology** — 8-stage life evolution, habitable zones, Goldilocks conditions
- **Civilization** — Trade routes, first contact, Great Filter, Dyson spheres, warp gates, interstellar ships
- **Consciousness** — Cosmic Mind network, Omega Point, simulation self-awareness, eternal recurrence
- **Audio** — 11-layer procedural synthesizer: drones, harmonic pad, arpeggiator, crystal bells, heartbeat, wind, proximity audio, event sounds, reverb, chirp, mic reactivity
- **Music** — Star positions become melodies ("Music of the Spheres")
- **Art** — Particle painter, cosmic art generator, poster generator, star trails
- **Poetry** — Cosmic haiku, constellation lore, universe narration
- **Gamification** — 78 achievements, 11 challenges, 22 codex entries
- **Meta** — Dreams, universe letters, timelapse, developer commentary, final narration

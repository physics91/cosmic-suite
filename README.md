## Architecture

```
portal.html          — Orbital hub · Musica Universalis · cosmic memory
index.html           — Digital Cosmos (4679 lines, the flagship)
[28 experiences]     — Each self-contained, zero shared code
404.html             — "Lost in Space" error page
```

**Cross-experience systems:**
- **BroadcastChannel** — All experiences pulse heartbeats; portal shows which are alive
- **localStorage** — Visit tracking, epoch progression, high scores, lifetime stats
- **Cosmic Seed** — Daily seed shared across experiences via URL parameter
